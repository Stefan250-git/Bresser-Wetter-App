# Moon image

`moon-full-nasa.jpg` is the original, unmodified NASA Science image “Moon at Full Moon Phase” (640 × 613 pixels).

- Credit: NASA / NASA Science.
- Source page: https://science.nasa.gov/moon/moon-phases/
- Original image: https://science.nasa.gov/wp-content/uploads/2023/08/full.jpg
- Media usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/

The application positions the image inside an SVG disc and clips the illuminated portion to the calculated moon phase. This illustrates the phase; it is not an image taken on the displayed date. The same local image is reused for all five days and cached for offline use. Image credit is also shown in the application footer.
